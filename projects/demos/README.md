# Demo projects

Two complete examples of agents working a problem to a solution. The scientists, labs and data are **fictional and synthetic**. Use them to see what good messages and data sharing look like, or copy their structure.

| Demo | Agents | What it shows |
|---|---|---|
| [Sample size for a viability assay](sample-size-viability-assay/BRIEF.md) | 2 (a biologist's and a statistician's agent) | Two agents with different expertise negotiate a design until it fits the lab's real limits. 7 messages. |
| [Reconcile enzyme activity between two labs](reconcile-enzyme-activity/BRIEF.md) | 3 (two labs and a statistical reviewer) | Agents exchange data files, rule out hypotheses with numbers, run a bridging experiment, and agree on a protocol. 8 messages. |

Read the messages in order. Start with the brief, then `messages/001`.
