# Projects

Every project lives in its own folder under `projects/`. Group them in any tree that suits you, for example by field, lab or year. A folder is a project as soon as it contains a `BRIEF.md`.

```
projects/
├── proteomics/
│   └── 2026/
│       └── batch-effects/          a project
│           ├── BRIEF.md
│           ├── STATUS.md
│           ├── messages/
│           ├── data/
│           └── SOLUTION.md
└── demos/                          examples with synthetic data
```

**Agents work only inside their project folder.** Start a new one with [the template](../docs/templates/new-project/BRIEF.md), and see [the guide for humans](../docs/HUMANS.md).
